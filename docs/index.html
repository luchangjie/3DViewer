#项目简介

不依赖任何图形 API 的软件光栅化器

这是一个完全用软件实现的 3D 光栅化渲染器：所有三角形的逐像素遍历与着色都在 CUDA 核函数里完成，不调用 Direct3D / OpenGL 等任何图形 API。CPU 侧用 C++ / Win32 负责窗口、消息循环与摄像机交互，渲染内核由 NVCC 编译为 DLL 供主程序调用。项目为 "鼎甲杯"答辩开发，目标平台为 RTX 5060 Laptop（Blackwell 架构，sm_120）。

#核心特性

从加载、着色到交互的完整能力

🧊

纯软件光栅化

暴力像素-三角形遍历，无图形 API 依赖，渲染逻辑完全可控。

⚡

CUDA 加速内核

NVCC 编译 render.cu 为 DLL，逐像素并行光栅化跑在 GPU 上。

💡

Blinn-Phong 着色

实现基础光照模型，呈现有体积感的明暗过渡。

📦

OBJ 模型加载

支持打开并渲染 .obj 模型，坚持保留原始面数、不做自动降面。

🧱

体素模式

可将模型以体素形式呈现，并导出 voxel 的 .obj 文件。

🎥

自由视角控制

旋转 / 平移 / 缩放 / 线框切换，实时观察模型。

#操作说明

运行 exe 后的交互快捷键

按键 / 操作功能
鼠标左键拖拽旋转模型
鼠标右键拖拽移动视角（视觉上移动模型）
鼠标滚轮缩放（推近 / 拉远）
W切换线框 / 实体显示模式
O打开 OBJ 文件对话框
V切换体素模式
G导出 voxel 的 obj 文件（普通模式无效）
R重置摄像机位置
ESC退出程序

#技术架构

构建链与渲染内核接口

Win32 / C++ 主程序
窗口、消息循环、摄像机控制、模型 / 体素数据加载（cl / MSVC 编译）。
→
CUDA 渲染内核 (render.cu → DLL)
NVCC 编译。导出四接口：
cudaInit / UploadTriangles / Render / Shutdown。
→
GPU 逐像素光栅化
暴力遍历三角形 + Blinn-Phong 着色，输出帧缓冲。

当前正在推进 BVH 加速结构，以突破约 1.5 万面的渲染性能瓶颈（目前为无加速结构的暴力遍历）。

#构建与运行

本地编译步骤（详见 部署说明.md）

  1. 安装 Visual Studio（含 MSVC 工具链）与 CUDA Toolkit 12.x。
  2. 用 NVCC 编译 render_kernel（render.cu）生成渲染 DLL。
  3. 用 cl（MSVC）编译主程序（main.cpp 等）生成 exe。
  4. 运行 exe，按 O 打开 OBJ 模型即可开始渲染。
