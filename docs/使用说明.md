# 3D Viewer - GPU 光栅化渲染器 使用说明

## 系统要求

- 操作系统：Windows 10 / 11（64 位）
- 显卡：NVIDIA 独立显卡（需支持 CUDA，即 2012 年后的型号均可）
- 驱动：请安装 NVIDIA 官方显卡驱动（一般电脑自带，仅运行无需安装 CUDA Toolkit）
- 注意：不支持 AMD 显卡、Intel 集成显卡，无 NVIDIA 显卡将无法启动

## 目录文件

- `3DViewer.exe`：主程序
- `render_kernel.dll`：CUDA 渲染模块（必须与 exe 放在同一文件夹下）
- `*.obj`：你的 3D 模型文件（无需同目录，models 文件夹可放示例模型）

## 操作说明

- 鼠标左键拖拽：旋转模型
- 鼠标右键拖拽：平移视角
- 鼠标滚轮：缩放（推近 / 拉远）
- `O` 键：打开 OBJ 模型文件
- `W` 键：切换 线框模式 / 实体模式
- `V` 键：切换 体素模式（需要先打开 OBJ 文件）
- `G` 键：导出体素化模型为 OBJ（仅在体素模式下有效）
- `↑`（上箭头）：提高体素分辨率（体素模式下不可用，请在实体模式下调好再切换）
- `↓`（下箭头）：降低体素分辨率
- `R` 键：重置摄像机到默认视角
- `ESC` 键：退出程序

## 窗口标题信息

- `Tris`：当前三角形总数
- `FPS`：实时渲染帧率
- `Mode`：显示模式（Solid = 实体，Wire = 线框，Voxel = 体素）
- `Res`：体素分辨率

## 使用步骤

1. **启动程序**：首次启动会自动生成一个内置的立方体模型供测试。
2. **打开模型**：按下 `O` 键，在弹出窗口中选择 `.obj` 文件。支持标准的顶点坐标（`v`）和面（`f`）数据，暂不支持材质和贴图。
3. **查看模型**：使用鼠标左键旋转，右键平移，滚轮缩放来仔细查看模型。
4. **线框模式**：按下 `W` 键切换，可查看模型的三角网格分布。
5. **体素模式（乐高 / MC 风格）**：
   - 先用 `O` 键打开一个 OBJ 文件（内置立方体不支持此功能）。
   - 按 `↑` 或 `↓` 调整分辨率（标题栏可预览数值，数值越高越精细，计算越慢）。
   - 按下 `V` 键进入体素模式，等待片刻（由 CPU 计算，时间视模型复杂度和分辨率而定）。
   - 进入体素模式后，可按 `V` 键切回普通模式重新打开原模型。
   - 在体素模式下按 `G` 键可以导出当前体素模型为 OBJ 文件。
6. **重置视角**：任何时候按 `R` 键可以让模型回到画面中央。

## 常见问题

**问题**：`Res` 较大（> 500）时显示已构建，却无模型显示
**原因**：分块构建限定了每 16×16 像素范围可容纳的最大三角形数量，滚轮放大模型会逐渐显示。

**问题**：体素模式下提示“默认立方体模型不支持体素模式”
**原因**：内置示例模型无法体素化，请先按 `O` 键加载你的 `.obj` 文件。

**问题**：提示“CUDA 初始化失败”或“未发现 NVIDIA 显卡”
**原因**：没有检测到可用的 NVIDIA 显卡或驱动安装有问题。
